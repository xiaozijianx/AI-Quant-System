## 〇、用户确认的优化方向 (2026-08-15)

1. **组合风险分析必须放进多因子分析优化** —— 从三个 case(网格多因子/积极因子挖掘/清华)看, 清华最专业; 对比清华, 当前多因子最大的缺口是**组合风险模型分析**, 它没有出现在多因子优化流程里
2. **输入确认**: 选一组因子 → 单因子分析 → 多因子评价 → 构建因子包; 组合风险必须放入此流程
3. **多因子目前只支持技术面因子** —— 单因子会做各类型, 但多因子组合仅支持技术面
4. **Barra 风格因子是组合风险模型的默认底座**, 不适合放因子包, 适合放**所有因子覆盖的通用阶段**; 即使因子包里没选 Barra 因子, 风险分析也要做

## 一、当前多因子分析全貌 (现状盘点)

### 1.1 流程 (两套入口, 结构一致)
```
输入: factor_ids(一组因子) + 股票池 + 日期 + 调仓周期 + 中性化 + 时序窗口
  │
  ├─ Stage A: 单因子预评价 (按类型: technical / technical_ts / financial / signal)
  ├─ B1 数据准备: 仅 technical+technical_ts 构建截面 + 预处理(3倍MAD + 中位数填充 + 中性化)
  ├─ B2 合成评价: 合成方法(等权/IC加权/排名/Lasso/ML回归/ML分类/Markowitz/Optuna/Sharpe/PCA)
  │             + 组合评价(IC/分层/Top-N集中度/基准对照/超额/Calmar/月度胜率/多空/L5-L1)
  └─ 输出: 因子包 (weights + direction + ml_model_path + pca_model_path + result_snapshot)
```

### 1.2 已覆盖能力 (相对专业化已不错的)
- walk-forward 滚动训练、purged_kfold_cv、blending/voting/stacking(ML 合成)
- 因子筛选(IC阈值/非空率/覆盖率) + 冗余剔除(相关性>0.8) + 方向自动判断
- IC 加权合成用滚动历史 IC(walk-forward, 无未来函数)
- 组合回测: Top-N/基准/超额/Calmar/月度胜率/多空/L5-L1
- 因子包持久化 + 切页恢复

## 三、核心不足与优化方案

### 3.1 不足一: 组合风险模型缺失 (用户点1/2/3/7) → F1

**现状**: B2 输出"合成因子值 → 组合回测 → 绩效指标", 但没有组合对风格的暴露度量、风险分解、组合中性化、归因。

**目标**: 多因子合成后自动附加一个**通用 Barra 风险阶段**, 不依赖用户是否选中 Barra 因子。

```
B2 合成 → 组合权重 (Top-N)
   │
   └─ 通用风险阶段 (Barra 10 风格, 引擎自动算暴露, 无论因子包是否含 Barra):
        ① 组合风格暴露 = Σ 权重 × 个股暴露 (柱状图, 对标基准)
        ② 风险分解: 总风险 ≈ 风格风险 + 特质风险 (需因子协方差)
        ③ 组合风格中性化: 优化权重贴近基准 (get_port_neutral 等价)
        ④ 归因: 组合超额收益 = 风格贡献 + alpha 贡献
```

**关键设计**: Barra 暴露计算作为**引擎通用基础设施**(factor_engine 提供 `build_barra_exposure`), 任何组合分析自动调用; 因子包里不需要包含 BARRA_* 因子。

### 3.2 不足二: 只支持技术类合成 (用户点5/6) → F2

**现状**: `technical_ids = technical + technical_ts`; financial/signal 只单因子展示, 不进合成。

**各类型入合成的可行性分析**:

| 类型 | 特征 | 进合成方案 | 难度 |
|---|---|---|---|
| technical | 连续日频、截面可比 | 直接进合成(现状) | ✅ 已有 |
| technical_ts | 绝对量纲(价格/累积) | 先时序分位标准化再入截面(现状) | ✅ 已有 |
| financial | 季度低频、财报期对齐 | 财报可用日 asof 对齐后进截面; 调仓对齐财报期; 天然低频注意更新频率 | ⚠️ 中 |
| signal | 离散 0/1 或 -1/0/+1、稀疏 | 不能直接 IC 加权; 转"信号方向得分"或"事件暴露" | ⚠️ 中 |

**推荐方案: 分轨合成 + 汇总展示** (不强行把信号塞进连续因子合成):
- **轨1 连续因子**: technical + technical_ts + 财务(对齐后) → 多因子合成(现有方法)
- **轨2 财务因子**: 财报对齐, 参与连续合成或单独合成
- **轨3 信号因子**: 事件评价 + 信号组合分(按命中率/条件收益加权 → 信号强度分), 单独合成
- **汇总**: 综合因子包或分轨展示

> 开放决策(待确认): 财务因子进连续合成(量纲统一后) vs 单独合成; 信号因子转数值 vs 保持事件评价单独成轨。

### 3.3 不足三: Barra 非通用默认底座 (用户点7) → F1 核心

- Barra 在因子库里, 但**风险分析不应依赖用户是否选中 Barra 因子**
- 做成"所有因子组合都自动附加的通用风险阶段"
- 这也意味着 Barra 因子**不适合进因子包**(它们不是 alpha 来源, 是风险标尺); 因子包只管 alpha 因子, 风险阶段在包外统一执行

### 3.4 其他可能缺失功能 (用户点4, 待确认勾选) → F3

对照清华 + 行业标准"专业化多因子流程", 还可能有以下增强:

| 候选 | 说明 | 优先级建议 |
|---|---|---|
| 因子衰减接入合成 | 用 D5 的持有期衰减选最优调仓周期, 合成时按衰减定 rebal | 中 |
| 增量 alpha / 正交化 | 新因子相对已有因子的正交化后 IC(增量信息) | 中 |
| 组合换手/成本敏感性 | 换手率、成本对净 alpha 的影响曲线 | 低 |
| 调仓周期/中性化敏感性 | 稳健性分析(不同 rebal/neutralize 下 IC/绩效) | 中 |
| 多基准对照 | 加行业基准/风格基准 | 低 |
| 滚动权重/IC 演化可视化 | walk-forward 权重的时序展示 | 中 |
| ML 重训稳定性 | 滚动重训的稳定性/漂移 | 低 |

## 四、F 阶段实施完成 (2026-08-15)

- **F0 (预检+容错)**: preflight_factors + auto_match_factors + 前端实时提示与展示
- **F1 (核心)**: 组合风险分析 —— Barra 通用底座(6 价量风格, 不依赖选中 Barra 因子) + 组合风格暴露 + 风险分解(风格+特质占比+年化波动) + 组合中性化(可选) + 归因(风格贡献+alpha)
- **F2**: 多类型因子覆盖 —— 财务进连续合成(财报对齐) + 信号方向得分独立轨(混合/仅信号) + 方法×类型自动匹配
- **F3**: 因子包增强 —— 组合风险快照(portfolio_risk_snapshot) + 因子×方法一致性校验
- **F4**: 全库回归 —— 7 组后端冒烟 + 前端浏览器冒烟, 全部通过

## 五、实施要点 (已实现)

- 引擎新增 `build_barra_style_panels(panel)` 通用函数(复用 BARRA_* 公式/算子), 任何组合分析自动调用
- 因子协方差矩阵: 由 Barra 因子收益时序构建(截面回归估计 ridge, 保证可逆)
- 组合风险分析: 自动附加于 B2 结果(容错: 失败不影响主评价), 不依赖用户选中 Barra 因子
- 多类型合成: financial 用财报对齐, signal 转方向得分(±1/0), 分轨后汇总叠加(次级倾斜系数 0.5)
- 前端 Tab4 多因子分析: 新增"组合风险分析"结果区(暴露柱状图/风险分解环形图/归因堆积图/Top-N 切换/中性化信息) + "信号方向得分轨"展示区
- 仅信号: 综合方向得分当单一合成因子(__signal_combo__)走同一条管线, 因子包保存时映射回真实信号因子ID
