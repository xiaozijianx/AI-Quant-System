# 因子库页面架构重构计划

> 目标：让因子库页面下的“因子库 / 因子构建 / 因子评价 / 因子挖掘”等页面在前后端文件结构上分层清晰、互相低耦合；屏蔽或删除任一页面/子页面不影响其他页面。

## 一、目标架构

### 后端

```
routes/
  factor/                     # 因子库总路由包
    __init__.py               # 组装 router
    library.py                # 因子库：列表/详情/保存/初始化/分类/基类
    construction.py           # 因子构建：算子/字段/试算
    evaluation.py             # 因子评价：evaluate/trial/batch_evaluate/single
    multifactor.py            # 多因子合成/因子包
    mining/
      __init__.py             # mining 公共入口
      common.py               # mining/status、SSE 任务状态等
      gp.py                   # GP 挖掘
      rl.py                   # RL 挖掘
      llm_gp.py               # LLM 增强 GP
      svd.py                  # SVD 挖掘
      ml.py                   # ML 挖掘
  factor_rl.py                # 可选：RL 独立路由（若想完全独立可保留）
```

### 前端

```
templates/factor/
  base.html                   # 因子库页面外壳/Tab 导航
  library.html                # 因子库子页面
  construction.html           # 因子构建子页面
  evaluation.html             # 因子评价子页面
  multifactor.html            # 多因子/因子包子页面
  mining/
    index.html                # 因子挖掘总页面壳
    gp.html                   # GP 子 Tab
    rl.html                   # RL 子 Tab
    llm_gp.html               # LLM 增强 GP 子 Tab
    svd.html                  # SVD 子 Tab
    ml.html                   # ML 子 Tab
```

### 公共层

```
lib/
  factor_screening.py         # 公共筛选/评价函数（从 factor_gp 抽出）
  factor_db.py                # 因子库读写
  factor_init.py              # 初始化
  factor_evaluator.py         # 通用评价
  factor_engine/              # 表达式引擎（后续拆包）
  mining/                     # 各挖掘引擎（GP/RL/LLM/SVD/ML）
```

## 二、执行顺序

### Stage 1：后端路由包化

- [ ] 将 `routes/factor.py` 迁移为 `routes/factor/` 包
- [ ] 保留现有功能不变量
- [ ] 把 `mine_rl` 路由独立到 `routes/factor/mining/rl.py` 或保留 `routes/factor_rl.py`
- [ ] 验证所有 `/api/factor/*` 路由正常

### Stage 2：前端模板拆分

- [ ] 将 `templates/factor.html` 拆成多个子模板
- [ ] 先拆 RL 子 Tab 到 `templates/factor/mining/rl.html`
- [ ] 再拆 GP / LLM-GP / SVD / ML
- [ ] 最后拆因子库/构建/评价/多因子

### Stage 3：公共函数下沉

- [ ] 将 `oos_recheck`、`walk_forward_recheck`、`permutation_significance`、`dedup_by_corr` 从 `factor_gp.py` 迁移到 `factor_screening.py`
- [ ] 让 `factor_rl` 只依赖 `factor_screening.py`
- [ ] 让 GP / LLM-GP 也改为引用 `factor_screening.py`

### Stage 4：页面独立性验证

- [ ] 屏蔽/删除 GP 路由后，RL 路由可独立启动
- [ ] 屏蔽/删除 LLM-GP 路由后，RL 路由可独立启动
- [ ] 前端隐藏 GP/LLM 子 Tab 后，RL 子 Tab 可正常使用
