## 一、最终目标

**挑选出有效的因子 → 以合适的组合、合适的权重 → 用于选股。**

多因子分析不是"测试这些因子好不好"，而是要把一批因子加工成一个可用的选股信号。因此完整的流程必须包含"筛选 → 去冗余 → 合成 → 组合评价 → 选股"五个环节。

---

## 二、多因子工程全流程（参考）

```
【数据层】股票池 → 日K面板 + 财务面板(财报期对齐)
    ↓
【因子计算】factor_library → calc_factor 逐因子算面板
    ↓
【单因子评价】逐因子: 预处理(去极值→Zscore→中性化) → IC/IR/分层/多空 → 有效性判定
    ↓
【因子筛选】基于 IC 阈值 淘汰无效因子；相关性矩阵(跨期平均) 剔除 |corr|>0.8 冗余
    ↓
【因子合成】多方法: 等权 / IC加权(walk-forward) / 排名打分 / Lasso / ML / Markowitz / PCA / Optuna优化权重
    ↓
【组合评价】对合成 alpha: IC时序 / 分层单调性 / Top-N集中度 / 绩效(夏普/回撤/换手)
    ↓
【选股输出】合成因子值排名 → Top-N 持仓 → 下阶段对接实盘
```

## 四、各 CASE 关键实现对照

### 1. 因子预处理（CASE-C / 机器学习case）
顺序: **去极值(MAD) → 标准化(Z-score) → 中性化(行业/板块/市值)**
- `winsorize_mad`: 3倍MAD截断
- `zscore`: 标准化到 mean=0/std=1
- `industry_neutralize`: 行业内Z-score；`neutralize`(机器学习case): 行业哑变量 + ln市值 回归取残差

### 2. 单因子评价
- 逐个因子算 IC（截面 Spearman/Pearson）、IR、分层收益
- 你的系统 `run_ic_timeseries_panel` / CASE-C `calc_ic` / 网格 `calc_ic_series` 均如此

### 3. 因子相关性
- 你的系统 `factor_correlation_matrix`: 两两 Spearman 相关矩阵（**仅末截面**）
- 清华 `CorrValue`: 因子值截面相关，**跨期取平均**；`CorrRet`: 因子收益相关
- 清华 gl23_day3_tick `cutFactors`: 相关性>阈值去冗余

### 4. 因子合成（权重确定）
| 方法 | 实现 | 说明 |
|---|---|---|
| 等权 | `mean(axis=1)` | 基线 |
| IC加权 | `权重=历史IC均值/Σ\|IC\|` | walk-forward，有效因子权重大 |
| 排名打分 | 截面排名归一化+方向翻转+加权 | 网格 score_stocks |
| Lasso | 因子矩阵X + 未来收益y，Lasso稀疏回归 | 自动剔除无效因子 |
| ML(树模型) | 因子值→未来收益 回归/分类 | 非线性映射，输出预测收益/概率 |
| Markowitz | `scipy.optimize.minimize(最大夏普, Σw=1)` | 清华 day1_A |
| PCA | 主成分加权合成 | 降维去相关 |
| Optuna | 贝叶斯优化搜索权重/超参 | 自动调优 |

### 5. 最终选股
- 合成因子值排名 → Top-N 持仓（你的系统 `_multifactor_topn_backtest`）

## 六、机器学习多因子：它到底在做什么

### 核心逻辑（当前系统 `_ml_fit_model` + `synth_multi_factor_eval` 的 ml 分支）
- **输入**: 历史截面的因子值矩阵 X（每只股票一行，每个因子一列）
- **标签**: 该截面之后 rebal_period 的未来收益 y
- **学习目标**: 训练一个函数 `f(因子值) → 收益`
- **输出**: 对当期每只股票 `f(因子值)` 的**预测收益**，当"综合因子值"使用
- **选股**: 按预测收益高低排名，预测收益高的买入

### 与等权/IC加权的本质区别
- **等权/IC加权**: 显式权重，把因子线性加权成"因子强度分"（可解释，输出的是"分数"）
- **ML**: 隐式非线性映射，直接输出"收益预测"（不可直接解释，输出的是"预测收益"）

**关键澄清**: ML 的"综合因子值"其实就是模型的"预测收益"。选股 = 按预测收益排序。它与 Lasso 的区别仅在于：Lasso 是线性+稀疏，ML树模型是非线性+可捕获因子交互。

### 输出到底是不是权重？
- 当前实现 **不显式输出权重**，权重隐含在模型内部（每个特征的重要性可单独提取）
- 若要显式权重，可改用 Lasso（系数即权重）或线性回归

## 七、不同机器学习模型的区别与应用场景

| 模型 | 类型 | 特点 | 适用场景 |
|---|---|---|---|
| XGBoost | 梯度提升树 | 非线性、带L1/L2正则、处理缺失、中小样本强 | 默认首选，表格数据 |
| LightGBM | 梯度提升树 | 直方图算法更快、叶子生长、适合大数据 | 大数据量、追求速度 |
| RandomForest | Bagging集成 | 方差低、不易过拟合、精度通常略低 | 需要稳健、防过拟合 |
| Lasso | 线性稀疏回归 | 线性+自动特征选择(系数压0) | 需要可解释权重 + 特征筛选 |
| Optuna | 贝叶斯优化(调参) | 自动搜索最优权重/超参数 | 权重/超参数自动寻优 |

### Optuna 是不是机器学习？
Optuna 本质是**超参数优化工具**（贝叶斯优化/TPE），不是"训练模型"，而是"自动找模型/权重的最优参数"。它属于**元学习/自动调参（AutoML）**范畴。当前系统没有它。

## 八、ML 工程级的正确做法（参考机器学习CASE，当前缺失）
1. 标签用 **binary 涨跌概率**（`predict_proba`），比回归收益更稳
2. **purged K-Fold 时序CV**，训练/验证间留 gap 防泄漏
3. **集成/stacking** 多模型融合
4. **特征重要性** 提取 → 反馈到因子筛选闭环
