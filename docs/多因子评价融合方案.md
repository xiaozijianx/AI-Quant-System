# 多因子评价融合方案

> 融合来源：`CASE-网格与多因子`、`CASE-机器学习因子挖掘`、`CASE-C-多因子选股`（清华/华泰思路）
> 状态：**已落地** — 原"规划落盘，待实现"; 全套流程(Stage A~E + 信号独立轨 + 组合风险 F1)已在 F 阶段实现, 详见 [因子库F阶段-综合多因子分析设计文档.md](./因子库F阶段-综合多因子分析设计文档.md)

## 一、目标

在因子库页面勾选**多个因子**后，进入「多因子分析」子页面，对勾选因子做多因子组合分析。与单因子评价的区别：

- 单因子评价：逐个因子独立算 IC / 分层 / 绩效。
- 多因子评价：先对每个因子做单因子预评价 → 筛选 → 合成组合 alpha → 对组合做 IC / 分层 / Top-N 集中度 / 绩效回测。

## 二、三类因子的处理策略

| 因子类型 | 能否进多因子合成 | 处理方式 |
|---------|:---:|---------|
| 技术类（连续） | ✅ | 参与筛选 / 相关性 / 合成 / 组合评价 |
| 财务类（季度离散） | ❌ | 单独走财报期对齐单因子评价，结果按序展示 |
| 形态类（离散信号） | ❌ | 单独走信号评价（命中率/条件收益），结果按序展示 |

原则：多因子合成只针对技术类连续因子；选中财务/形态因子时，仅做单因子评价并顺序展示，不进合成。

## 三、总体流程（五阶段）

```
用户在因子库勾选多因子 → 进入「多因子分析」子页面
   ├─ Stage A  单因子预评价（每个选中因子按类型走单因子评价）
   ├─ Stage B  因子筛选 + 相关性分析（仅技术类）
   ├─ Stage C  多因子合成（仅技术类，多方法可选）
   ├─ Stage D  组合评价（合成 alpha 的 IC/分层/Top-N/绩效）
   └─ Stage E  汇总展示（单因子结果 + 组合结果，顺序从上到下）
```

## 四、各阶段设计

### Stage A：单因子预评价
- 复用现有 `/evaluate` 单因子逻辑（已按 technical/pattern/financial 分流）。
- 输出每个因子的 IC / ICIR / 有效性分级 / 分层 / 信号 / 财报对齐结果。

### Stage B：因子筛选 + 相关性分析（仅技术类）
- 有效性筛选：剔除 IC 均值过低、样本不足、非空率过低的因子。
- 相关性矩阵：技术类因子两两 Spearman 相关，热力图展示；相关性 > 0.8 的冗余组提示。

### Stage C：多因子合成（仅技术类，多方法）
统一用 `calc_factor`（读 formula 递归计算）算每个因子的面板值，对每个截面做预处理（去极值 + Z-score + 行业/板块/概念/市值中性化），再合成。方法：

| 方法 | 来源 | 说明 |
|------|------|------|
| `equal` 等权 | CASE-C | 标准化后取均值 |
| `ic_weighted` IC加权 | CASE-C | 权重 = 前 `ic_lookback` 期历史 IC 滚动均值（walk-forward，不偷看当期） |
| `rank_score` 排名打分 | 网格 | 横截面排名归一化 + 方向翻转 + 加权 |
| `lasso` 稀疏回归 | CASE-C | walk-forward 训练（历史因子拟合未来收益，预测当期） |
| `ml` 机器学习 | 机器学习case + 网格ML | 滚动 walk-forward XGBoost/LightGBM，输出概率因子再走 IC/分层 |

### Stage D：组合评价
对合成 alpha 做：
- **IC 时序**：合成 alpha 与未来收益的截面 IC / RankIC / ICIR / 胜率。
- **分层回测**：分 5 层看各层收益单调性 + 多空收益（L5-L1）。
- **Top-N 集中度回测**：Top5 / Top10 / Top20 等权组合的累计收益与回撤对比。
- **基准对照**：沪深300（取不到用样本等权），计算超额收益。
- **绩效指标**：累计 / 年化 / 夏普 / 最大回撤 / 卡玛 / 月度胜率 / 换手。

### Stage E：汇总展示（前端）
从上到下顺序展示：
1. 勾选因子清单 + 各自单因子评价结果。
2. 技术类因子相关性矩阵热力图。
3. 合成方式选择 + 组合 IC / 分层 / Top-N / 绩效。
4. 「一键 AI 分析」按钮（复用 `sendEvalToAi`，把单因子 + 组合结果一并填入 AI 框）。

## 五、依赖的现有函数（复用）

- `factor_engine.preprocess_factors`（去极值 + Z-score + 行业/板块/概念中性化）
- `factor_engine.calc_ic / calc_ir`
- `factor_engine.equal_weight_synthesis / ic_weighted_synthesis / lasso_synthesis`
- `factor_engine.run_layered_backtest`
- `evaluate_pattern_factor`（形态因子信号评价）
- `financial_report_rebal_dates`（财务因子财报期对齐）

## 六、需新增函数

1. `rank_score_synthesis`：横截面排名归一化 + 方向翻转 + 加权（网格 score_stocks）。
2. `factor_correlation_matrix`：技术类因子两两 Spearman 相关矩阵。
3. `marketcap_neutralize`：行业哑变量 + ln(市值) 回归取残差（机器学习 case）。
4. `walk_forward_ic_weighted`：用前 `ic_lookback` 期历史 IC 滚动均值做权重。
5. `ml_synthesis`：滚动 walk-forward XGBoost/LightGBM，输出概率因子。
6. `run_multi_factor_eval`：多因子评价主流程（Stage A->D）。

## 七、前端

- 在 `factor.html` 新增/升级「多因子分析」子页面（独立于单因子评价展示，可独立 Tab）。
- 展示：单因子结果列表、相关性热力图、合成方式选择、组合 IC/分层/Top-N/绩效图。

## 八、验收标准

1. 技术类多因子可完成「预评价 → 筛选 → 合成 → 组合评价」全流程。
2. 选中的财务/形态因子被单独评价并顺序展示，不进合成。
3. IC 加权为 walk-forward（历史 IC），无未来函数。
4. 前端展示单因子结果 + 相关性 + 组合评价，顺序清晰。
5. 不破坏现有单因子评价功能。
