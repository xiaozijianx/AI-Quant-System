#### 2.7.5 复合因子构造算子（`day2_M.ipynb`，WorldQuant 风格，因子库「因子构造」核心）
这些算子以「原始字段（Open/High/Low/Close/Volume/VWAP/TotalRet/AMktCap）+ 算子」构造复合因子，是搭建因子构造功能的基础函数：

| 算子 | 说明 | 实现要点 |
|------|------|----------|
| `ts_Delay(df, n)` | 滞后 n 期 | `df.shift(n)` |
| `ts_Mean(df, n)` | n 期等权移动平均 | `df.rolling(n).mean()`（滑动平均） |
| `ts_Decay(df, n)` | n 期线性衰减加权均值 | 权重 `w_i=(n-i)/n`，近期权重高 |
| `ts_DecayExp(df, n)` | n 期指数/非线性衰减均值 | 权重取正态分布分位数 `norm.ppf((n-j)/n)` |
| `ts_Max / ts_Min(df, n)` | n 期滚动最高/最低 | `rolling(n).max()/min()` |
| `ts_Delta(df, n)` | n 期差值（当前-n期前） | `df - ts_Delay(df, n)` |
| `ts_Stdev(df, n)` | n 期滚动标准差 | `rolling(n).std()` |
| `ts_Sum(df, n)` | n 期滚动求和 | `rolling(n).sum()` |
| `ts_Kurtosis / ts_Skewness / ts_Median` | n 期峰度/偏度/中位数 | `rolling(n).kurt()/skew()/median()` |
| `pn_TransNorm(df)` | 截面排名→正态分位数变换 | `rank(axis=1)` → `norm.ppf`，消除量纲差异 |
| `Repmat(df, val)` | 一维值扩展到全列 | 用于基准对齐 |

**标准构造流程**：原始字段 → `ts_*` 算子组合 → `pn_TransNorm` 截面标准化 → 取特定截面（如周五/月末）→ 与未来收益算 IC 择时。

## 2.10 SVD 隐因子挖掘（`CASE-QuantStats绩效分析与报告/2-SVD因子挖掘与分析.py`）

以 Fama-French 模型 `R = B·F + e` 为思想，对收益率矩阵做 SVD/主成分分解，**让数据自己说话**挖掘隐因子：

- **流程**：收益率矩阵去均值 → `np.linalg.svd` 分解 → 奇异值衰减判断有效因子数（累计方差 80%/90%）→ 因子暴露解读（行业分组）→ 滚动窗口 SVD 观察市场状态切换（齐涨齐跌/板块分化/个股行情）→ SVD 降维压缩 50+ 因子为 K 主成分对比 XGBoost AUC。
- **应用**：因子压缩降维（PCA 预处理）、隐因子溯源、个股残差分析（独立行情/alpha 信号识别）。

## 3. 因子评价方法与代码分析

### 3.1 因子预处理（三件套）

| 步骤 | 方法 | 代码位置 |
|------|------|----------|
| 去极值 | MAD Winsorize（中位数±N×1.4826×MAD） | `CASE-C-多因子选股/preprocessor.py` `winsorize_mad`；`feature_engine.py` `preprocess_features` |
| 标准化 | Z-score：(x-mean)/std | `preprocessor.py` `zscore` |
| 中性化 | 行业内 Z-score；行业市值回归取残差 | `preprocessor.py` `industry_neutralize`；`feature_engine.py` `neutralize` |
| 分位数正态变换 | rank→正态分位数 | `qinghua/day_M.ipynb` `pn_TransNorm` |

### 3.2 单因子有效性评价

| 指标 | 定义 | 说明 | 代码 |
|------|------|------|------|
| IC | 因子值与未来收益的相关系数（pearson/spearman） | 越大越准 | `CASE-C-多因子选股/synthesizer.py` `calc_ic` |
| Rank IC | 秩相关，不受极值影响 | 最常用 | 同上 `method="spearman"` |
| IR | IC均值/IC标准差 | >0.5 优秀，>0.2 可用 | `synthesizer.py` `calc_ir` |
| IC 正比例 | positive ratio | 稳定性 | `layered_backtest.py` |

### 3.3 分层回测与组合评价

| 方法 | 说明 | 代码 |
|------|------|------|
| 分层回测 | 按 alpha 分 5 层，比较各层累计收益 | `CASE-C-多因子选股/layered_backtest.py` `run_layered_backtest` |
| 多空收益 | 第5层 - 第1层（L5-L1） | 同上 `long_short` |

## 6. 因子挖掘方式全景（SVD / 机器学习 / 神经网络）

### 6.1 SVD 隐因子挖掘（`CASE-QuantStats绩效分析与报告/2-SVD因子挖掘与分析.py`）

- **原理**：Fama-French 模型 `R = B·F + e`，用矩阵分解「让数据自己说话」。
- **流程**：收益率矩阵去均值 → `np.linalg.svd` → 奇异值衰减定因子数（累计方差 80%/90%）→ 因子暴露行业分组解读 → 滚动 SVD 观察市场状态（齐涨齐跌/板块分化/个股行情）→ 降维压缩 50+ 因子为 K 主成分对比 XGBoost AUC。
- **应用**：因子压缩降维（PCA 预处理）、隐因子溯源、个股残差分析（独立 alpha 识别）。

### 6.2 机器学习因子挖掘（监督学习）

| XGBoost 截面 | 集成树 | 财务+技术 | 华泰金工 231 因子参考, 已实现 52 | 机器学习因子挖掘 |

| MLP | 全连接 | 截面特征 | 打分选股 | 主/多因子 |

| 方法 | 类型 | 核心思想 | 备注 |
