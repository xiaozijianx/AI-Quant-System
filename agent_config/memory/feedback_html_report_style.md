保存研报为 HTML 文件时，采用"兴森科技_002436_五步法研报_20260817.html"的版式与生成流程。

**版式结构（自上而下）**：
1. 深蓝渐变封面（标题+副标题+报告日期/收盘价/总市值/板块/报告期 meta 行）
2. 顶部评级横幅（评级大字 + 一句话结论）
3. 五步法五张卡片（step-badge 圆标 1-5 + 标题 + 正文，含表格/高亮/note/danger 块）
4. 数据来源附录表格（数据类型→来源，标注 CSV/年报页码/新闻链接）
5. 免责声明页脚

**CSS 要点**：深蓝主色 #1a3a6b、红强调 #c0392b、卡片圆角+阴影、表格深蓝表头、@media 移动端适配、自包含无外部依赖。

**生成流程（关键）**：
1. 用 Python 脚本定义多个字符串片段（P1~P6 分别对应头部CSS/五步正文/结尾）拼接生成，**禁止用 editor 多次手工增量插入 HTML 标签**——曾因增量编辑导致 div 未闭合、封面/评级横幅嵌套错位；
2. 生成后用 HTMLParser 脚本验证：div 标签配对、无未闭合标签、章节顺序正确，验证通过才算完成；
3. 文件保存至 `outputs/reports/`，命名 `<股票名>_<代码>_五步法研报_<日期>.html`。

**Why:** 用户 2026-08-17 在兴森科技研报任务中明确表示"这种生成html研报文件的格式我挺喜欢的，请记下来，以后就这么做"；同日手工增量编辑生成的首版 HTML 出现结构错乱，改用脚本拼接+校验后通过，证明脚本法是可靠路径。

**How to apply:** 今后任何 write-report 任务中，用户要求"保存为 html/生成研报文件"时，默认按上述版式与脚本生成流程执行，无需再询问格式；若用户指定其他样式再偏离此模板。
