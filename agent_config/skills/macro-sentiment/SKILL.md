# macro-sentiment 技能

宏观情绪与风险指标分析，监控A股及全球宏观情绪指标，输出综合恐慌/贪婪评分。

## 数据来源

### A股市场情绪
- **上证50ETF QVIX（中国波指）**：通过 akshare 获取上证50ETF期权波动率指数，类似中国版"VIX"，反映A股大盘蓝筹恐慌程度（<16平静，16-22正常，22-28焦虑，28-35恐慌，>35极度恐慌）
- **上证指数近期表现**：近10日涨跌幅，判断趋势
- **北向资金净买额**：沪股通+深股通合计净买额（亿元），反映外资对A股配置态度
- **融资余额**：深市融资余额及变化趋势，反映市场杠杆情绪

### 全球宏观指标
- **VIX恐慌指数**：FRED (VIXCLS)，衡量标普500隐含波动率（<15平静，15-20正常，20-25焦虑，25-35恐慌，>35极度恐慌）
- **美国10年期国债收益率**：akshare，全球资产定价之锚（<3.8宽松预期，3.8-4.3分水岭，>4.4偏紧，>4.8高利率压制）

## Workflow

执行脚本获取宏观情绪指标，返回结构化数据。

## 可用脚本

| 脚本 | 功能 | 参数 |
|------|------|------|
| `scripts/macro_sentiment.py` | 获取所有宏观情绪指标，计算综合评分 | `--mode`, `--output_dir` |

### 参数说明

- `--mode`：数据范围，可选 `all`（默认，A股+全球）、`china`（仅A股）、`global`（仅全球）
- `--output_dir`：输出目录，默认 `./data`

## 预期输出

脚本返回结构化 JSON，包含以下字段：

### A股市场情绪
- `china_qvix`：上证50ETF QVIX（中国波指/恐慌指数），含当前值、等级、描述
- `shanghai_index`：上证指数最新收盘价及近10日涨跌幅
- `north_flow`：北向资金净买额（亿元），正值表示外资流入
- `margin`：融资余额及变化趋势，反映杠杆情绪

### 全球宏观指标
- `vix`：VIX恐慌指数，含当前值、风险等级、日期
- `us10y`：美国10年期国债收益率（%），含当前值、风险等级

### 综合评分（composite）
- `composite_fear_greed_index`：综合恐慌/贪婪评分（0-100），基于QVIX波动率、北向资金、融资余额变化综合计算
- `overall_sentiment`：整体情绪判定（极度恐慌/恐慌/中性/贪婪/极度贪婪）
- `action_suggestion`：操作建议
- `score_details`：各指标对评分的贡献明细（含指标名、值、分值变化、解释）

## Error Handling

- **网络错误**：提示用户检查网络后重试
- **数据源失败**：单个指标获取失败不影响其他指标，失败指标标记为 null
- **无数据**：提示用户检查网络或稍后重试
