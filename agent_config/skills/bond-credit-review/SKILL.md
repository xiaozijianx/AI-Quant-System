# bond-credit-review 技能

债券信用基本面审查，输出信用评分、风险点清单和投资建议。本技能无脚本，由 LLM 直接进行信用审查综合评估。

工作方式：收集发行人财务数据和舆情信息；由 LLM 直接进行信用审查综合评估；输出信用评分 + 风险点清单 + 投资建议。

> 适用范围：城投债、产业债的信用基本面分析。请勿用于利率债、可转债等。

## Prerequisites

- 发行人数据可能需要先收集，请勿假设发行人数据一定存在
- 数据收集是 Step 2 LLM 分析的前提

## Workflow

完整信用审查走 Step 1→2→3。用户只需要信用评分或风险点时，执行 Step 1→2 后从结果中提取所需信息，跳过 Step 3。

### Step 1: 收集发行人数据

信用审查任务开始时执行。请勿跳过此步骤直接执行 Step 2，LLM 分析需要数据输入。

根据发行人类型，通过 `skills` 工具加载相应能力技能收集数据：

- 城投债：需要发行人财务数据 + 区域经济数据 + 舆情信息
  - 发行人财务指标 → `financial-analysis` 技能
  - 区域经济/行业数据/最新公告 → 通过 `use_mcp_tool` 调用 MCP 网页搜索/提取工具
  - 舆情/事件驱动信号 → `sentiment-analysis` 技能
- 产业债：需要发行人财务数据 + 行业数据 + 舆情信息
  - 发行人财务指标 → `financial-analysis` 技能
  - 行业数据/最新公告 → 通过 `use_mcp_tool` 调用 MCP 网页搜索/提取工具
  - 舆情/事件驱动信号 → `sentiment-analysis` 技能

预期输出为发行人财务和舆情数据素材。

### Step 2: 信用审查分析

Step 1 数据收集完成后，基于收集到的数据由 LLM 直接进行信用审查分析（本技能无脚本，不调用任何脚本）。Analyze the bond credit rating based on the collected data. Consider:

- 发行人财务状况：资产负债率、现金流、盈利能力、短期偿债能力
- 城投债额外考虑：区域经济实力（GDP/财政收入）、政府性基金收入、平台地位、隐性债务
- 产业债额外考虑：行业景气度、竞争格局、产业链地位
- 舆情信息：是否存在负面事件、评级下调、违规处罚
- 信用评分：综合上述因素给出信用评分（如 AAA/AA+/AA/AA- 等）
- 风险点清单：列出主要风险点及严重程度
- 投资建议：给出投资建议（适合/谨慎/回避）

预期输出为信用评分 + 风险点清单 + 投资建议。

### Step 3: 输出信用审查报告

Step 2 完成后（用户需要完整报告时）执行。基于 Step 2 的 LLM 分析结果整理为结构化报告。若用户只需要信用评分或风险点，可跳过此步。

## Script Reference

`scripts/` 目录下无脚本，Step 2 的信用审查分析由 LLM 直接完成，不调用任何脚本。

## 分析规则

1. **债券类型必须明确**：分析时必须明确债券类型为 `城投` 或 `产业`，不同类型考虑维度不同
2. **数据收集是前提**：Step 2 的 LLM 分析依赖 Step 1 的数据收集结果

## Error Handling

- **发行人数据缺失**：先回到 Step 1 收集缺失数据，再进入 Step 2。
- **债券类型不明确**：向用户询问是城投债还是产业债，再开始分析。

**IMPORTANT**: Do not 跳过 Step 1 直接执行 Step 2（LLM 分析需要数据输入）。Do not 假设发行人数据一定存在，若数据缺失需先收集。请勿用本技能分析利率债或可转债（不适用）。
