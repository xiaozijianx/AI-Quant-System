# stock-price 技能

通过 MiniQMT 实时获取 A 股行情数据（最新价、涨跌幅、历史 K 线、成交量等）。本技能是查询股价/K线数据的唯一正确途径，请勿使用网络搜索。

## Prerequisites

在执行 Workflow 之前，请确认以下前置条件：

1. **MiniQMT 客户端已运行并登录**：本技能依赖 MiniQMT 提供实时行情接口。
2. **xtquant 包已安装**：Python 环境中需可导入 `xtquant`。

## Workflow

### Step 1: 获取 K 线数据

当用户询问股价/K线/走势/成交量时执行此步骤。根据用户意图选择合适的周期与条数：

- 用户问最新价/涨跌幅（如"贵州茅台现在多少钱"）：周期 `1d`，条数 `1`，从返回数据最后一条读取最新价
- 用户问近期走势（如"贵州茅台最近走势如何"）：周期 `1d`，条数 `30`（约一个月）
- 用户问 K 线图（如"看一下贵州茅台日 K 线"）：周期 `1d`，条数 `100`（默认）
- 用户问分钟级走势（如"贵州茅台今天盘中走势"）：周期 `1m` 或 `5m`，条数 `240`（一个交易日）
- 用户问成交量（如"贵州茅台最近成交量放大了吗"）：周期 `1d`，条数 `30`，重点关注返回数据中的 volume 列

```bash
python agent_config/skills/stock-price/scripts/get_kline.py <股票代码> [周期] [条数]
```

参数说明：

- `<股票代码>`（必填）：带交易所后缀，如 `600519.SH`、`000858.SZ`、`688981.SH`
- `[周期]`（可选）：默认 `1d`，支持 `1m` / `5m` / `15m` / `30m` / `1h` / `1d` / `1w` / `1mon`
- `[条数]`（可选）：默认 `100`

脚本预期输出 K 线数据表格（日期 / 开盘 / 收盘 / 最高 / 最低 / 成交量）。

**脚本调用约定**：

- `scripts/` 目录下只有 1 个主脚本 `get_kline.py`，由 Step 1 调用。
- 股票代码必须带交易所后缀（上交所 `.SH`、深交所 `.SZ`、科创板 `.SH`）。
- 若用户提供的是公司名称（如"贵州茅台"），请先转换为股票代码（→ `600519.SH`）再调用。

## Error Handling

- **报错 `xtquant not found`**：提示用户安装 xtquant 包。
- **报错 `MiniQMT not running` 或连接失败**：提示用户启动 MiniQMT 客户端并登录。请勿假设 MiniQMT 一定在运行。
- **用户提供公司名称而非股票代码**：先转换为带后缀的股票代码再调用脚本。

**IMPORTANT**: Do not use 网络搜索查询股价/涨跌幅/K线数据，本技能是唯一正确途径。请勿给 `get_kline.py` 传递不带后缀的股票代码。
