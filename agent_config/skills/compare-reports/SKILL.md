# compare-reports 技能

对比两家/多家公司年报中的**叙述性内容**差异（业务描述、战略方向、风险因素、客户供应商等），输出结构化的差异分析。本技能同时支持对比同一公司不同时期财报的内容变化（跨期对比）。

工作方式：先检查需要对比的公司年报 RAG 索引是否已存在；若索引不存在，需要先下载对应公司的年报并构建索引；然后调用对比脚本生成差异分析报告。

> 结构化财务数字对比请改用 `financial-analysis` 技能的 `peer_compare.py`。

## Prerequisites

- 本技能需要年报 RAG 索引已存在（位于 `data/vector_store/`）
- 请勿假设索引一定存在；索引可能缺失，缺失时需要先补齐再执行对比

## Workflow

执行 Step 1（检查索引）→ 索引齐全直接 Step 2（跨公司对比）/ 索引缺失先下载补齐 → Step 2。用户要求对比同一公司不同时期的财报时，执行 Step 1（检查索引）→ 索引齐全 Step 3（跨期对比）/ 索引缺失先下载补齐  → Step 3。多家公司对比时需检查所有涉及公司的索引。

### Step 1: 检查需要对比的公司年报 RAG 索引

对比任务开始时，首先检查所有涉及公司的索引。请用 `read_files` 尝试读取 `data/vector_store/` 目录，确认索引是否存在。

- 预期输出：索引存在/不存在状态
- 若所有公司索引都存在：直接进入 Step 2/3
- 若某公司索引不存在：使用 `read-pdf` 技能下载该公司的年报并构建索引

> 索引缺失时请勿放弃对比任务，应先通过 `read-pdf` 技能补齐索引再执行对比，让用户看到完整的对比结果。

### Step 2: 调用对比脚本生成差异分析（跨公司）

所有公司的年报索引都已存在后执行此步骤。

```bash
python agent_config/skills/compare-reports/scripts/cross_company.py --stocks <代码1,代码2,...> --topic "<对比维度>"
```

> 注意：对比脚本需加载 embedding 模型、FAISS 索引并调用 LLM 生成分析，首次执行或索引较大时可能需要 1~3 分钟。调用 `run_commands` 时请显式设置 `timeout: 300`（秒），避免默认超时中断。

参数说明：

- `--stocks`（必填）：多个股票代码逗号分隔，**不带交易所后缀**，如 `600519,000858`
- `--topic`（必填）：对比维度关键词，如 `业务布局`、`风险因素`、`客户集中度`、`供应链`

预期输出为结构化差异分析报告（各公司在该维度的描述对比 + 差异总结）。

### Step 3: 调用跨期对比脚本（同一公司不同时期）

当用户要求对比同一公司不同时期的财报内容时执行此步骤，默认场景为 Step 2 跨公司对比。

```bash
python agent_config/skills/compare-reports/scripts/cross_period.py --stock <股票代码> --topics "<对比维度>"
```

> 注意：与 Step 2 相同，跨期对比脚本同样需要加载 RAG 索引并调用 LLM，耗时较长。调用 `run_commands` 时请显式设置 `timeout: 300`（秒）。若本地无该公司的索引，请先通过 `read-pdf` 技能下载年报并构建索引（下载构建耗时 1~5 分钟，`timeout` 建议 `300`），再执行本步骤。

参数说明：

- `--stock`（必填）：单个股票代码，**不带交易所后缀**，如 `600519`
- `--topics`（必填）：对比维度关键词，逗号分隔，如 `营收,净利润,毛利率`
- `--index_dir`（可选）：索引目录，默认 `data/vector_store`

预期输出为同一公司不同时期的财报内容对比分析。

## Script Reference

`scripts/` 目录下有 2 个主脚本：

- `cross_company.py` — 跨公司年报对比，Step 2 使用
- `cross_period.py` — 跨期财报对比，Step 3 使用

**脚本调用约定**：

1. 股票代码不带后缀：`--stocks` 参数用不带后缀的代码，如 `600519,000858`
2. 对比维度要简洁：用 `业务布局` 而非 `对比业务布局`
3. 多公司对比时至少两家公司：`--stocks` 至少包含 2 个股票代码

## Error Handling

- **索引不存在**：回到 Step 1 检查并下载缺失的索引。
- **查询无结果**：尝试调整 `--topic` 关键词。

**IMPORTANT**: Do not 假设索引一定存在，若 Step 1 检查发现缺失必须先补齐。Do not fabricate data，索引缺失时请勿编造内容，应先补齐索引再执行对比。请勿用本技能对比结构化财务数字（那是 `financial-analysis` 技能的职责）。
